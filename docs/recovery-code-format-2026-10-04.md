# 账号恢复码前缀

恢复码统一使用 `mlyz{账号ID}-{原编码}`：ID 0 为 `mlyz0-…`，ID 1 为 `mlyz1-…`，ID 2 为 `mlyz2-…`。原编码保持不变。

个人页显示和复制共用格式化函数，账号 ID 来自当前会话的账号接口。找回时解析新格式并核对服务端返回的账号 ID；不匹配或格式错误时保留当前账号。根据用户后续要求，已移除旧码兼容：页面找回入口拒绝 `xy1-` 和无前缀旧码，且不会发出找回请求。

验证：请求与会话测试 17 项通过，包含 ID 0/1/2 新码、原有 UUID 后缀、旧格式拒绝且不发请求、不切换账号、错误格式与 ID 不匹配；类型检查及生产 H5 构建通过。旧码被拒绝时显示停用提示，并保留当前账号栏显示。
