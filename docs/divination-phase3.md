# 第三阶段第一批：梅花年月日时起卦

实现日期：2026-10-03。研究依据见 [易卦接入调研](research/yijing-integration.md)。本批只扩展梅花时间法，六爻纳甲等后续能力仍按研究路线分批接入。

## 已接入

页面 `/pages/divination/index` 现在支持三种独立方法：六爻记录、梅花两数、梅花时间。时间法使用填写的问事日期、时刻和实际 UTC 偏移，不要求填写两数，不引入随机值。

时间法的新方法名为 `meihua-calendar`，规则版本为 `meihua-calendar-v1`；原有 `liuyao-manual`、`meihua-two-numbers` 继续采用 `divination-v1`，原计算和恢复语义保留。

## 采用的规则

1. 原始当地钟表日期/时间减去填写的 UTC 偏移，得到 UTC 瞬间；再统一换算为固定 UTC+08:00 演算时间。
2. 采用现有锁定依赖 `lunar-typescript@1.8.6` 转农历。以正月初一换年，不使用立春年界。
3. 年支按子 1、丑 2 至亥 12 取数；农历月、日按数字取值；闰月保留标记并取同名月份数字，如闰六月仍取 6。
4. 23:00–00:59 为子时，01:00–02:59 为丑时，依此类推；日期在北京时间 00:00 改变，23:00–23:59 仍使用当日农历。
5. 年支序数＋农历月＋农历日，除 8 取上卦；该和再加时支序数，除 8 取下卦、除 6 取动爻。余 0 分别取坤 8 与上爻 6。
6. 唯一动爻所在经卦为用，另一经卦为体。互卦沿用现有本卦结构互卦，包括乾坤取自身，不改用“乾坤无互，互其变卦”的另一约定。

固定 UTC+8、00:00 换日和闰月取同月数均明确标注为本工具约定。古籍没有给出现代时区及这些边界的统一规则，页面不把这些选择写成古法唯一标准。

输入公历日期、转换后的 UTC 日期和固定 UTC+8 日期都必须位于 1900–2099；转换越界即报错。此新增限制仅适用于新时间法，旧方法的 v1 历史记录仍按原来的输入日期验证和计算语义恢复。

## 可追溯结果

结果包含原输入与 UTC 瞬间、北京时间、农历年/月/日与年支、闰月标记、时支、四个取数、年月日和与加时总数、取余、卦象、互卦、体用、规则约定、引擎名称/版本、计算步骤和来源链接。

页面并列显示原问事地时刻与演算时间，闰月另作提示。计算过程展开年支、农历月日和时支的取数，方便核对。完整时间约定在起卦前和结果内都可读到。

实际历史偏移仍由用户填写；页面明确要求包含当年夏令时，没有新增自动 IANA 查询或真太阳时功能。“填入当前时刻”按当前选择的偏移填入钟表时间。

## 记录兼容

- 保留原存储键 `oasis.divination.records.v1` 和 `schemaVersion: 1`，容纳三个方法的混合记录。
- 保存记录仍只存原始输入、保存时间、ID 和明确规则版本；查看和导出按方法对应的版本复算。新结果中的 UTC、农历、取数和来源随导出一起保留。
- 读取、保存、恢复及导出检查方法/规则版本配对。时间法不能标作 `divination-v1`，旧两法也不能标作 `meihua-calendar-v1`；未知版本和损坏记录报错，保留原存储，不自动迁移覆盖。
- 沿用 50 条容量上限、唯一 ID、手动保存、删除确认和 JSON 导出。无账号上传、云同步或 AI 调用。
- 后续若升级历法引擎或改变时间约定，必须保留本版本复算路径或提供明确迁移，不能在旧版本标识下静默改变算法。

## 独立验收依据

[《梅花易数》卷一](https://zh.wikisource.org/zh-hans/梅花易數/卷一)提供两组完整预期：

| 古籍例 | 原文参数 | 原文结果 | 用于端到端测试的现代同参日期 |
|---|---|---|---|
| 观梅占 | 辰年十二月十七申时 | 革，初爻动变咸，互乾巽 | 2025-01-16 15:00 UTC+8 |
| 牡丹占 | 巳年三月十六卯时 | 姤，五爻动变鼎，互重乾 | 2025-04-13 05:00 UTC+8 |

现代日期的农历对应，以及 2025-01-29 春节、2025-07-25 闰六月初一、2025-08-23 七月初一，取自[香港天文台 2025 年文字对照表](https://www.hko.gov.hk/tc/gts/time/calendar/text/files/T2025c.txt)。现代同参日期不表示古代事件实际发生于这些公历日期。卦象预期来自古籍，历日预期来自 HKO，不使用待测函数自身输出作为独立参考。

`npm run typecheck`：全项目通过。最终统一构建与 UI 验收以主任务结果为准；本文件不把未执行的浏览器或小程序真机验收写成通过。
