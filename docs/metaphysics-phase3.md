# 第三批接入：先完成十八项研究，再接入两项能力

日期：2026-10-03。基于[十八项总路线](metaphysics-integration-roadmap.md)，本轮先完成四份专题分析，再实施梅花年月日时起卦与西方指定时刻行运。十八项指本项目已提出的范围，不表示十八项都已完成开发。

## 本轮范围

| 交付 | 用户入口 | 计算与资料约定 |
| --- | --- | --- |
| 十八项目录 | 五术探索 → 山医命相卜 | 补齐七政四余、印度占星、太乙、择日、姓名文化；标明已接入范围及待核事项 |
| 梅花年月日时起卦 | 一事一记 → 年月日时方法 | 当地问事时刻与有效 UTC 偏移 → UTC → 固定北京时间农历；保存年支、月、日、时支取数与算式 |
| 西方行运快照 | 三盘同参 → 历史时区、出生地点与观察日期 | 指定日期固定 UTC+8 中午，也就是 UTC 04:00；十行运天体对十本命天体的有向相位 |

首批未新增运行依赖或后端服务。基础事实在本机计算；用户明确保存后才写入本机档案。原有服务端八字 AI 报告仍使用原入口。

## 结果与档案

出生计算总规则升级为 `3.0.0`，档案格式仍是兼容的 `schemaVersion: 1`。行运结果的可选 `observation` 保存日期、固定偏移、12:00、UTC 瞬间、1° 容许度和独立规则标识。未填观察日期不生成行运；打开旧档案继续展示保存时的结果，不能因新版本发布自动补算行运。选“填入资料”并重新计算才形成新版结果。

易卦旧方法保留 `divination-v1` 的复算规则，新年月日时法另记版本，读取时校验方法与版本配对。详细规则与验收见[梅花时间法交付](divination-phase3.md)；西方天文参考、阈值和支持范围见[行运交付](metaphysics-transits.md)。

## 当前边界

梅花时间法的固定 UTC+8、农历正月换年、00:00 换日、闰月同月数是本软件的明确约定。手动偏移需要包含问事当年的夏令时；不宣称自动解析历史时区或校正真太阳时。六爻仍是基础卦象记录，纳甲等列入下一批。

西方行运是某一瞬间的快照。五类相位统一 1° 容许度，本命相位仍为 6°；不计算一整天的命中窗口，也未加入行运宫位、行运对四轴、事件预测或其他宫制。固定观察偏移与出生资料可选 IANA 历史时区是两种不同时间口径。

研究为奇门、六壬、太乙、七政四余、印度占星等列出可实施的最小范围、候选许可和独立参考盘要求。它们在目录中继续为待接入，不能由本批两项功能推称已全部支持。
