# 猫来运转手机界面：猫咪陪伴版

## 方向与来源

为本人和朋友在 Android / iPhone 浏览器中查询、阅读报告而设计。参考用户指定的“测测”亲切、轻松的产品气质，保留猫来运转的功能范围；没有照搬其品牌、页面或素材。

- GitHub skill：[ceorkm/mobile-app-ui-design](https://github.com/ceorkm/mobile-app-ui-design)。已安装到用户 Codex skills 目录，本轮采用其移动端层级、触摸目标、表单与状态反馈指导。
- 本机 skill：`make-interfaces-feel-better`，用于间距、按压反馈、焦点与减少动态效果等细节。
- 产品参考：[测测官网](https://www.cece.com/)。
- 猫咪采用用户确认的蓝布衣三花形象：`oasis-uniapp/src/static/ui/cat-calico-sprite.webp`；六种表情由 `CatCompanion` 统一显示。素材为本地透明图片，配套线性图标同目录，不依赖外部图片服务或图标包。旧 SVG 保留但不再作为陪伴组件的图片。

## 视觉约定

奶白背景 `#faf8fc`、柔紫主色 `#7760b2`、深紫灰正文 `#302b40`。薄荷色与暖杏色仅用于次要入口、建议和状态区。使用中文系统字体；正文 16px、辅助文字 12/14px、标题 18/24/28px。表单输入保持 16px，降低 iPhone 聚焦放大造成的布局跳动。

布局以 4/8px 为间距单位，内容最大宽度 560px。按钮与主要可操作区域至少 44px；底部提交区考虑安全区域。通过 `prefers-reduced-motion` 降低动画。小猫主要出现在欢迎、空状态和等待页，不遮挡报告正文。

## 页面变化

| 页面 | 变化 |
| --- | --- |
| 今日 | 三花小先生与每日运势在最上；黄历可展开；下面进入八字解读和塔罗手记 |
| 出生资料 | 性别直接点选，5 项填写进度，按账号保存本机草稿；错误定位到字段；固定底部提交按钮 |
| 报告列表 | 普通历史记录列表，展示解读名称、出生资料与创建时间；点击查看详情；保留空状态、创建入口、刷新和加载更多 |
| 报告详情 | 先阅读解读与生活建议，再查看四柱；章节跳转，完整排盘展开，大运显示当前阶段；可直接进入今日查询 |
| 我的 | 报告入口、恢复码复制与手动保存、展开旧账号恢复表单；恢复失败保留当前账号 |

历史记录按接口返回的创建时间倒序展示，不显示状态分类、状态标签或进度文案；可通过“加载更多手记”继续查看历史分页。详情页仍根据实际生成进度显示等待、解读或重试。出生草稿保留在本机账号对应的存储键中，提交成功后清除。AI 文本按纯文本渲染基础 Markdown 标题和列表，不执行 HTML。

## 验证

- 前端 TypeScript 检查、5 项请求/账号回归测试、H5 本地与 Docker 构建通过。
- Chromium 手机视口 390px / 320px 检查；首页、表单、报告、空状态、个人页无横向溢出。
- 表单刷新恢复草稿、缺项校验、新建报告、状态轮询、键盘展开排盘、按报告查询今日内容已实际操作。
- 报告空状态、错误恢复码的行内提示、恢复失败后保留当前账号、断网退出加载状态与恢复联网后重试通过。
- 使用本机模拟 AI 与隔离 MySQL，未调用付费模型。本轮没有 Android / iPhone 真机；Safari 真机和公网 HTTPS 仍需部署后验收。

本机预览地址：`http://localhost:18080`。复用 `docker-compose.mobile.yml` 发布，操作见 `deploy/MOBILE_GUIDE.md`。

## 三花小先生接入

首页支持轻点小猫：切换藏鱼干/陪伴表情和一句短回应，4.5 秒后恢复欢迎状态；离开页面会清除计时器。回应区预留高度，避免下方入口跳动。使用按钮支持键盘 Enter/空格，并遵循减少动态效果的设置。

解读等待时翻书、报告封面递卷轴、空状态和错误时伸爪陪伴、个人页打盹。阅读正文不增加悬浮小猫。素材规范、来源和本轮验证见 [calico-companion.md](./calico-companion.md)。
