# 阶段七：大六壬本地排课

本阶段交付独立本地规则引擎、起课页面和档案流程。路由由主集成修改，页面为 `pages/liuren/index`。

## 已实现

- 公历起课：1900–2099 年、输入年月日时分秒和显式 UTC 偏移；换算 UTC+08:00，23 点换日，中气瞬间换月将。
- 古例核对：合法六十甲子日、月将、占时直接起课，不造公历日期；内置元首古例填表按钮。
- 全十二天地盘、四课、九宗门三传、十二天将、日旬空、每盘取传依据。未知的无法唯一取传分支只给天地盘和四课，三传留空并标明原因。
- 完整输入、历算信息、盘面、来源及规则版本的本机快照；30 份上限、读取不重排、复制资料再起课、单份／全部 JSON 导出、删除确认。
- 存储读取失败、结构错误、版本冲突、重复 ID 或写入失败均明确报错，不覆盖旧记录。不上传或调用 AI。

## 规则与验证边界

规则版本 `liuren-daqquan-jiuzong-v1`；采用《六壬大全》九宗门，涉害依据《订讹》的途中地支与寄干计数（排除起止位），同深取孟仲季及阴阳干支课优先。昼夜贵人按卯至申为昼，非当地日出日落。详细出处、分歧与原例在 [liuren-validation.md](research/liuren-validation.md)。

22 份古例 fixture 在引擎前写入；九宗门都有古例，其中涉害含 4 例、伏吟含有克／阴阳／自刑、返吟含有克与无克。前 3 例另核对原书三传所乘天将。全 720 组合只检查结构与终止，不宣称全量外部准确率；全部组合在本版规则下能取传，保留 unsupported 防护以免规则扩展时伪造结果。

32 项测试覆盖古例、计数、自刑、天将、输入、时区、中气精确边界、23 点换日、档案隔离与损坏保护。命令：`node --test tests/liuren-chart.test.mjs`。后续太乙页面完成时全项目 `npm run typecheck` 已通过。集成验收已核对元首古例午卯子及青龙／朱雀／天后，保存后刷新回看原盘成功，320px 无横向溢出。
