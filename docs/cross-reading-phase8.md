# 主题同读（第八阶段）

实现位置：`oasis-uniapp/src/domain/cross-reading/`、`src/pages/cross-reading/index.vue`。规则 `cross-reading-v1`，原创固定阅读提示 `cross-reading-prompts-v1`。

## 范围与交互

用户填写 1–100 字主题和最多 4000 字笔记，自主选取 2–8 份已存档案。可来自同一体系，也可以属于不同人、事项、日期；不根据姓名、生日、问题文字自动认定身份或合并事件。选择时复制记录，刷新来源列表不悄悄替换已选副本。

目前读取 19 类：出生三盘、流年流月、印度占星、西方星盘研究、七政天文对照、清历宿度、奇门、六壬、太乙、易卦、日期筛选、塔罗、黄历、空间事实、八宅、节气生活、静心练习、姓名文化、相学文献。每类单独调用原仓库的读取与校验接口，注入拒绝写入的存储适配器。一类损坏时显示该类错误，其他类仍可选择。练习仅收录已保存完成记录，进行中的草稿不参与。

结果按来源分组，每张卡列时间、规则版本、事实摘录、原口径与出处；默认显示前六项事实，可展开。三盘卡明确只摘录摘要和前三节各四项，西方跨盘相位明确只摘录前十二项；完整原数据均在副本中。用户笔记标记为原用户笔记，固定阅读提示标记为原创提示。没有调用 AI、生成个性化断语、总评分、运势或吉凶结论。

## 时间与资料差异

对照卡保留出生、出生加观测、两份出生、问事、日期窗口、天文时刻、手动古例、岁年标识、文化文本、空间测量、个人练习等独立语境。

差异区按事实显示各自时间基准、年界、月界或月将、日界与坐标制；多份出生或观测 UTC 不同时只说明不同，不判定录入错误。八字立春／十二节、紫微春节／农历月、晚子规则、六壬中气月将、宜忌 sect=1 的交节当天零点换月均保留。

旧三盘缺少独立规则元数据时显示“原快照未单列，请查看原盘口径”，不依据当下默认参数补出历史规则。西方三盘旧快照的宫制也要求查看原说明。

清历宿度只接受原模块保存的古法年标号和宫度，以《历象考成》1684 宿钤和每年 51 角秒规则查表；完整 28 宿表保存于原副本。年标号不作为出生年份，也不补造 UTC。与现代天文卡同读时单列差异，说明古表推移并非该年实测距星位置，单纯更换零点也不能把现代星位直接解释为古籍宿度。

太乙输入只标识岁年，保留原“未指定具体时刻年界”说明及 724 年积数锚文字分歧，不制造 UTC 日期。太乙的专用九宫不自动对应其他体系九宫；第 39、50 局原有待校勘主算继续留空，客算可独立呈现。相学文献里的借用星名与天文星名出现于同读时明确标注含义不同，不做外貌到命盘的推断。

## 旧易卦输入档案的处理

原易卦仓库只存输入和规则版本。因此仅在创建同读时，使用明确支持的四组方法／版本配对重建：手动六爻与两数梅花继续 `divination-v1`，历法梅花使用 `meihua-calendar-v1`，纳甲使用 `liuyao-najia-v1`。

卡片与差异区标记“本次依原规则重建”，不把它冒充当时保存的完整计算快照。同读保存原始输入档案及本次完整结果。重开同读不再次起卦、不重新查历法或星历，仅检查原输入、UTC、卦象几何、数值关系、固定纳甲关系、规则与出处是否一致。未知版本或方法版本不匹配拒绝重建，也不写回原易卦仓库。

## 保存、回看与导出

独立存储键 `oasis.cross-reading.records.v1`；最多 10 份，每份包含 2–8 份完整原记录、标题与保存时间、来源表示方式、事实卡、差异、固定提示、主题与笔记。单份 JSON 最大 850,000 字符，仓库最大 9,000,000 字符（这是序列化字符串长度限制，不是 UTF-8 字节数）。过大时要求减少选择，不静默删减原始资料。

通过共享 `snapshot-store` 保存。重开只读取同读仓库，不要求原档案仍存在。副本校验借用每个原仓库的私有单记录内存封套，不读取实时源仓库。删除同读不会删除来源。损坏封套、未知版本、重复键或内容结构不一致时停止保存、删除和导出，保留原数据；容量不足与读写失败有可见提示。

卡片、差异和提示根据已保存副本做一致性检查，非密码学防篡改。来源快照既有校验强度仍由对应模块负责，本页不宣称重新独立验算其全部历史事实。来源链接只将 HTTP/HTTPS 呈现为可点击项；原始链接仍完整留在原记录副本中。导出包含出生资料与笔记，页面提示用户保存下载文件。
