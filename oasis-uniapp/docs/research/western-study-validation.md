# 西方占星宫制与双人相位：固定规则及独立校验

核对日期：2026-10-03。实现为 `src/domain/western-study/`；固定样例为 `tests/fixtures/western-study-reference.json`，测试为 `tests/western-study.test.mjs`。

## 可验证的最小范围

本期新增从上升点起算的等宫制（ASC Equal House），与已有整宫制并列。Swiss Ephemeris 官方手册 §6.2.5 将等宫制定义为以 ASC 为第一宫头、其后按黄经每隔30°一宫。程序文档的宫制参数 `A` 或 `E` 对应该定义；`W` 是整宫制，`D` 是从 MC 起算的另一类等宫制，`V` 为 Vehlow，均不混用。

- [Swiss Ephemeris：宫制定义](https://www.astro.com/swisseph/swisseph.htm)
- [Swiss Ephemeris：宫制程序参数](https://www.astro.com/swisseph/swephprg.htm)

宫头以原始角度计算，含本宫宫头、不含下一宫宫头。落宫函数的 `1e-10°` 补偿只处理浮点减法在精确宫头处的舍入误差，远低于本项目的天文模型精度；不代表该精度的承诺。MC 作为独立角点保存，在这两种宫制中均不强制等于第十宫宫头。

双人比较为 Synastry 的跨盘本命相位：[Astrodienst 官方盘型说明](https://www.astro.com/faq/fq_fh_owtype_e.htm) 区分双盘天体互相位与 Composite Midpoint 的两盘中点位置。本页只比较实际A盘、B盘的天体，不产生第三张组合盘。

固定相位规则 `synastry-ten-bodies-major-six-degrees-v1`：

- A与B各取日、月、水、金、火、木、土、天王、海王、冥王，共100种有身份的跨盘组合。
- 包含同名天体组合；A太阳/B月亮与A月亮/B太阳是不同的组合。
- 最短圆周夹角限定五种主要相位：0°、60°、90°、120°、180°，全部统一容许度6°，包含边界。
- 不同相位没有各自不同的默认容许度；不区分入相／出相，不加入角点、交点、交叉落宫、行运关系或关系评分。
- 热带日期真黄经直接比较；不对不同时代的两盘作恒星参考架岁差校正。按照未舍入的相位偏差排序，显示只保留两位小数。

## 独立参考来源

参考数值来自官方公开 [Swiss Ephemeris 在线查询](https://www.astro.com/cgi/swetest.cgi)，页面显示版本2.10.03。全部为公历UT、默认地心视位置与热带日期黄道；未启用恒星黄道。正式运行使用现有 MIT 依赖 [Astronomy Engine 2.1.19](https://github.com/cosinekitty/astronomy)，没有集成 Swiss 的代码、服务调用或星历文件。

### 宫头

四组数据均以12:00 UT查询，格式为 `b=D.M.Y&n=1&s=1&p=b&f=Pl&arg=-ut12:00 -houseLONG,LAT,A`。JSON中保存了服务返回的完整12宫头、ASC与MC，不以被测函数生成期望值。

| 日期 | 地点与坐标（经度，纬度） | ASC | MC |
| --- | --- | ---: | ---: |
| 2000-01-01 | Delhi 77.209, 28.6139 | 100.1913130° | 357.4564554° |
| 1950-01-01 | London −0.1278, 51.5074 | 24.2718817° | 279.5945327° |
| 1990-01-01 | Sydney 151.2093, −33.8688 | 153.0916314° | 73.4833110° |
| 2024-03-20 | Shanghai 121.4737, 31.2304 | 205.7550367° | 117.8955285° |

48个宫头及8个独立角点，最大黄经圆周差为 **0.0000393803°**（约0.142角秒），测试阈值为0.002°。这些样例覆盖南北半球及ASC跨0°的宫头序列，不能据此保证全部日期和纬度的误差上界。

### 双人相位

四盘各保存10个官方星历黄经，并记录完整请求URL：

| 资料 | 当地时间与偏移 | 换算后的UTC |
| --- | --- | --- |
| a2000，纽约 | 1999-12-31 23:00，−5 | 2000-01-01 04:00 |
| b2000，上海 | 2000-08-16 12:00，+8 | 2000-08-16 04:00 |
| a1950，伦敦 | 1950-01-01 12:00，0 | 1950-01-01 12:00 |
| b1990，悉尼 | 1990-01-01 23:00，+11 | 1990-01-01 12:00 |

从上述固定的 Swiss 黄经十进制数，以独立 Python Decimal 运算生成全部跨盘夹角，再按固定五相位及6°阈值得到两组期望集合：`a2000/b2000` 为28个，`a1950/b1990` 为23个。它们是**独立星历加独立算术的参考**，不是第三方网站完整 Synastry 报告；测试不调用被测 TypeScript 相位函数去生成期望值。

40个天体黄经的实测最大差为 **0.0031696273°**（约11.411角秒），阈值0.02°。两组的天体身份／相位角集合全部一致，夹角／相位偏差的实测最大差为 **0.0034696741°**（约12.491角秒），阈值0.04°。参考数据距离6°阈值的最近余量分别约0.06449°和0.23728°，大于样例测得的位置误差；不以这些样例宣称阈值附近的所有真实命盘都与另一星历完全一致。

## 时间与降级规则

A、B分别经过已有 `normalizeBirth()`：各自的日期、时刻、手动UTC偏移或历史IANA时区独立解析。IANA夏令时重复时刻要求明确较早／较晚；不存在的跳时时刻报错。未知时刻不填默认中午，不允许未来出生资料。

两人的资料可以来自本机三盘档案，但仅读取出生资料，分别计算新的结果。通用资料中的性别只留档，不影响此处天体或相位算法。

某人缺地点、大约时间或纬度绝对值不小于66°时，仅该人的宫头／上升点／落宫停用，所有宫位值保存为null。其天体黄经和两盘相位仍对应明确填入的时刻，页面会说明这种限制；另一人的有效宫位照常提供。66°为本版产品支持范围，不声称等宫制数学定义只在该范围成立。
