# 五期：空间事实档案

实现日期：2026-10-03。版本 `space-record-v1`。本期提供手动空间记录、完整快照、本机档案和导出；不是八宅、玄空或其他风水排盘器。没有根据生日、房间文字、照片或时期猜测方位，没有生成风水吉凶，也没有调用传感器、地图或磁场模型。

## 输入与最小规则

名称必填，其余均可留空。输入包括地点备注、户型／房间文字描述、测量对象或观察姿势、原始角度与真北／磁北／未知基准、测量工具、公历日期、依据／误差备注、建筑时期、入住时期及补充观察。地点不要求精确地址；时期保留文字，不从大概年份推断传统运盘。

角度的录入约定是以所选北向为零点，顺时针记角度，范围为 `0 ≤ d < 360`。这是本工具保存读数的字段定义，不是自动核验工具输出的声明。页面提醒核对工具基准与设置：

- 空输入保存为 `null`，表示未测量，不能用 `Number('')` 自动变成 0°。
- 0° 是有效的明确读数。360° 拒绝保存，并提示用户确认后主动改填 0°；不静默归一化。
- 接受十进制有限数，拒绝负数、无穷、NaN、十六进制、指数形式及带单位文字。
- 未知基准的读数保持未知；缺少角度不补出朝向；磁北读数保持磁北。
- 本版不提供磁偏角输入或磁转真换算。因此不存在未填磁偏角却硬转真北的问题，也没有转换功能的精度／案例声明。
- 真北是用户注明的测量基准，软件只作记录，不代表已独立验证其准确度。

测量日期可留空，填写时验证 1900–2099 内的真实 `YYYY-MM-DD` 公历日期；不从未填日期推测测量当天。文字按字段设置上限，超限报错，不在保存时静默截断。表单保留中文、多行文字和“不详”等原始说明。

## 依据与资料许可

NOAA/NCEI 说明磁偏角是真北与磁北之间的夹角，会随位置和时间改变；由磁方位获取真方位需要磁偏角。这个事实支持将基准、日期与工具依据分开留档。[NOAA/NCEI 磁偏角说明](https://www.ngdc.noaa.gov/geomag/declination.shtml)

本页只链接上述来源并使用本项目自写的简短说明；没有复制 NOAA 原文、图像或标志，没有引入 WMM/IGRF 模型、磁偏角数据集或地图，不主张已取得这些素材的再分发许可。以后若加入转换或地图，应另行固定模型、位置、日期、误差和数据授权。当前快照的 `sources[].usage` 与页面来源栏记录了这个使用范围。用户自行填写的空间资料和外部资料的许可分别处理，不因引用 NOAA 就把用户资料标为 NOAA 数据。

## 存储与快照

独立键为 `__oasis_space_records_v1`，不读写出生档案、易卦记录或账号令牌。外层格式为 `{ version: 1, records: [...] }`，最多 30 份。每份记录包含独立 ID、UTC 保存时间及完整快照：

```text
schemaVersion: 1
ruleVersion: space-record-v1
scope: facts-only
recordedAt: UTC ISO 时间
facts: 全部录入字段，包括 null 方向和明确基准
directionStatus / directionNote: 保存时的记录状态说明
sources: 来源与使用范围
```

刷新、回看与导出都读取保存时的快照，不按当前表单重写旧记录。保存入参、返回对象、列表与导出对象彼此隔离；复制旧资料到表单后，再次保存会新增一份，不修改原件。名称相同也依 ID 区分。

存储读取失败、JSON 损坏、未知版本、非法字段、重复 ID 或不一致的方向状态都会阻止后续保存与删除，保留原始数据，页面提供重试。超过 30 份时拒绝新增，不自动淘汰旧档案。写入失败不显示成功，提示本次操作尚未确认；不承诺底层存储具有跨进程事务能力。

删除必须经过页面确认弹窗，取消不调用删除操作；实际操作仅删除指定 ID。找不到 ID 时不重写存储。应用数据被清理后本机档案也会消失，页面说明了这一点。

## 导出与页面

单份格式为 `oasis-space-record`，全部格式为 `oasis-space-records`，导出版本均为 1。导出保留全部快照、来源与保存时间，不访问账号资料或上传。H5 使用既有 `exportJson` 发起 JSON 下载，其他端复制 JSON 并提示自行粘贴保存；两种成功反馈分别显示。未实现导入，因此不会把导出的 JSON 自动写回或重新计算。

页面位于 `oasis-uniapp/src/pages/space/index.vue`，沿用 `AppButton`、`CatCompanion` 及米色／紫色样式。窄屏使用可收缩列、可换行按钮和 350px 以下样式，表单标签有可访问名称。保存或打开快照后等待 DOM 更新再滚动。路由、探索入口和共享目录由主任务注册，此子任务未修改这些文件。
