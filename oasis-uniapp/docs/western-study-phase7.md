# 西方占星宫制与双人相位首期交付

新增 `src/domain/western-study/` 与 `src/pages/western-study/`，在独立「星图之间」页面提供宫制对照及双人相位。旧西方本命盘适配器和原三盘类型保持兼容。

## 功能与流程

默认「单人宫制对照」，只要求A资料。切换到「双人相位比较」时填写B资料，两人的出生时刻、IANA或手动时区、地点完全独立。可以各自从本机三盘档案仅读取出生资料。

整宫制与ASC等宫制并列展示天体落宫，ASC、MC单独展示；可展开完整12宫头。双人模式另列十天体100种组合中符合规则的跨盘相位，按偏差排序。无相位有明确空状态，不生成组合中点盘或评分。

两种模式均支持命名、2000字笔记、本机保存／打开／删除、当前快照导出及全部档案导出。编辑出生资料或切换模式会使旧结果失效；修改笔记后再次保存为新档案，保留旧记录。

H5枚举使用原生select；日期和时间按YYYY-MM-DD／HH:mm明确填写。非H5保留picker。地点缺失、大约时刻或高纬度有按人区分的宫位不可用状态，未知时刻不填默认值。

## 版本与存储

- 主规则：`western-equal-synastry-study-v1`。
- 相位规则：`synastry-ten-bodies-major-six-degrees-v1`，五主要相位统一6°且包含边界。
- 计算引擎：Astronomy Engine 2.1.19，热带日期真黄道；无新增依赖。
- 存储键：`oasis.western-study.snapshots.v1`，最多20条、150万序列化字符，不自动淘汰记录。
- 快照保存各人的原始及解析后资料、UTC／时区选择、10天体、两种宫头和落宫、全部相位、模型／规则版本、来源与限制说明。

读取验证结构与已保存数据的一致性，仅对已有黄经做几何一致性检查，不重新查星历或解析历史时区。未知版本、损坏数据、重复ID、缺失相位、读取失败会阻止写入并保留原始数据；成功提示只在存储写入返回后出现。当前结果可在保存失败时独立导出。
