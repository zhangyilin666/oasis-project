# 第六阶段：指定流派奇门

已实现本地时家转盘拆补盘，规则版本 `qimen-zhuanpan-chaibu-kun2-v1`。原始公历时间与明确 UTC 偏移先转换到固定 UTC+08:00；23:00 子初换日，节气按历算时刻即时切换。甲／己符头定三元，采用中五永寄坤二、天禽随天芮、值使从旬首原宫计数、八神阳顺阴逆。星门本身沿固定外八宫序列整体转动。

页面新增 `src/pages/qimen/index.vue`，请由集成层注册路由与探索入口。本批不改共享导航。用户须选择日期、填写时分（可带秒）并明确选择偏移；地点为可选备注，不用于猜经度、时区或真太阳时。输出完整基本九宫、原地干、寄干、九星、八门、八神、符使及节气依据。无断语、应期、空亡、驿马、暗干等未校验附加功能。

本地独立键 `__oasis_qimen_records_v1` 保存最多 30 份完整输入与盘面快照。保存为新增记录、不淘汰；查看和导出不重算。单条删除需界面确认；读取错误、未知版本、重复编号、损坏盘位使保存／删除停止，以保留原值。单条与全部 JSON 导出只涉及此独立存储键。

历算复用已锁定的 `lunar-typescript@1.8.6`（MIT），奇门算法独立编写，没有新依赖、没有复制第三方排盘代码。现代教程只转录离散参考盘位，不引入文章、图片或断语。详见 [研究与参考](research/qimen-validation.md)。

定向验证：`node --test tests/qimen-chart.test.mjs`，15 项通过。包括 2 份作者公开全九宫盘、2 份外部历法＋原典规则实施前手算的夏至前后全盘，子初、交节、显式时区等价、中五的三个角色、1080 基本盘守恒、输入与档案错误路径。手算边界盘不冒称第三方发表盘；守恒枚举不冒称独立真值。全流派或全时段专业认证不在此次结论内。
