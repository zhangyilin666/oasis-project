# 清历黄道宿钤：底本、边界与独立核验

核对日期：2026-10-03。规则为 `qing-ecliptic-lodge-table-lookup-v1`，数值表为 `lixiang-kaocheng-1684-ecliptic-table-v1`。实现位于 `src/domain/qizheng-lodges/`，输入固定样例先于算法保存在 `tests/fixtures/qizheng-lodges-reference.json`。

## 范围与底本

采用《御制历象考成》四库全书本表卷十四的恒星黄道经纬度表，基准为康熙二十三年甲子，即1684年标号。公开影印表的11幅图片 `SK1530_figure_02415` 至 `02425` 已逐幅核读，录入每宿第一星的黄道经度。未将赤道宿度、其他年代的距星表或同宿其他恒星替换为边界。

- [《历象考成》表卷十四：原表和太阳算例](https://www.shidianguji.com/book/SK1530/chapter/1la1v7gbjjbjm)
- [《历象考成》恒星历理：七政宿度与黄道每年51角秒](https://www.shidianguji.com/book/SK1530/chapter/1la1uvjpyqx3d)
- [维基文库同卷原文：用于交叉核读方法和例题](https://zh.wikisource.org/zh-hans/御製厯象考成_(四庫全書本)/表卷14)
- [《五礼通考》卷195：宫度单位及初宫冬至起点](https://www.shidianguji.com/book/SK0367/chapter/1lcuu30rfqpsj)

这是一张**古法黄道宿钤查算表**，不构造现代星历或完整传统命盘。输入是用户明确指定的古法年标号和已经掌握的黄道宫度，不能把公历生日、现代星座宫位直接当作这里的输入。

## 单位和年移规则

原书周天360度，每宫30度；初宫初度从冬至点开始，三宫初度为春分点，六宫初度为夏至点，九宫初度为秋分点。角分、角秒都是六十进位。

内部全部为整数角秒：

```text
输入角秒 = (宫数 × 30 + 度) × 3600 + 分 × 60 + 秒
本年宿界 = (1684年宿界 + (年标号 − 1684) × 51) mod 1296000
宿宽 = (下一宿起点 − 本宿起点) mod 1296000
入宿度 = (输入角秒 − 本宿起点) mod 1296000
选取 0 ≤ 入宿度 < 宿宽 的唯一宿
```

每宿包含自身起点，不包含下一宿起点。原表末尾箕宿与斗宿之间跨周天零点，年移后跨零的宿也可能改变。显示秒只反映运算位数，原表仅列到分，并不代表测量达到秒级准确度。

春分零点转换仅为 `输入角秒 + 270°` 后取一周余数。它不重算天体或恒星位置，不校准现代黄道。

年标号1684对应康熙甲子，但输入不包含公历时间戳。程序不从1月1日、春节或冬至自动推断古历年界，也没有月日时的小数年改正。1684–2099是本版产品支持范围，不是史料声称的准确期；所有非1684年的结果都显示“按51角秒/年推移，未核对该岁年实测或修订宿表”。没有为1754或其他年份擅设准确度断点。

## 来源与使用方式

古籍原文属于公版。项目仅保存我们对古籍事实数值的独立转录、原创说明与公式实现，并提供章节链接和原图编号供追溯。不打包网站图像、现代译文、评论、OCR全文或第三方软件；临时查看的影印图片不进入项目发布文件。没有新增运行时依赖或外部计算服务。

罗睺、计都、月孛、紫气的传统位置没有在此核验，界面逐项标为未核。本页也不涉及赤道入宿度、命度、立命或运限。原有七政现代天文基础页面保持独立；不能把本查算表称作完整七政四余排盘复原。
