# 塔罗文字手录 · 第五批

更新：2026-10-03。交付范围为本机文字档案，使用 `tarot-manual-v1` 记录规则和 `rws-names-zh-v1` 牌名版本。无新增依赖。

## 最小规格与已实现行为

采用 RWS（韦特–史密斯）常见 78 张牌目：22 张大阿卡纳、权杖／圣杯／宝剑／星币四花色各 14 张小阿卡纳。大牌愚人为 0、力量为 8、正义为 11、世界为 21；小牌为 Ace、二至十、侍从、骑士、王后、国王。只保存牌名与分类，不接牌图、牌义、自动预测或随机抽牌。

中文名称是本工具统一用字，例如 High Priestess 为“女祭司”，Hanged Man 为“倒吊人”，Ace 为“王牌”，Pentacles 为“星币”。英文采用现代短名称（Strength、Judgement 等），不声称逐字复制原著章节标题。别名及实际牌组版本由用户写入牌组说明，其他体系不通过更改说明而自动切换牌目。

| 输入 | 约束 |
|---|---|
| 记录问题 | 1–200 字 |
| 记录日期 | 手动公历日期，1900-01-01 至 2099-12-31，验证真实日期；日期本身不参与推算 |
| 牌组说明 | 1–100 字，默认“韦特体系牌组” |
| 抽取过程 | 选填，0–200 字；记录用户实际过程，不模拟洗牌 |
| 单张 | 名称“单张关注”，位置“当下关注” |
| 三张 | 名称“三张复盘”，位置依次为“当前状况／需要留意／行动思考” |
| 自定义 | 1–10 张，牌阵名 1–60 字，每个位置名 1–40 字，位置名称各不相同 |
| 每张牌 | 本版合法牌 ID、正位或逆位、选填笔记 0–500 字 |
| 整体复盘 | 选填，0–2000 字 |

单张与三张是本工具的复盘模板，不声称为统一传统牌阵。默认正位在界面明确选中，可手动改为逆位。选择器先选类别再选牌名，当前牌阵已用牌不再列在其他位置的候选中；领域验证仍拒绝所有重复牌，包括同牌不同正逆位。本版只支持单副牌，多副重复牌未实现。

文本在新建时去除首尾空白，保留内部换行。快照读取不接受与该已保存格式不一致的文字，避免读取时悄悄改变旧记录。输入改动使预览失效，需要重新整理；另存只新增快照，不覆盖此前记录。切换牌阵时暂时隐藏的输入在本次页面会话中保留，只有当前显示的位置纳入记录。

页面使用现有 `AppButton`、`CatCompanion` 和米紫色主题。表单、选牌与结果均按单列组织，320px 下缩减内边距，牌名及笔记可换行。正逆位是独立文字标记，不通过旋转文字降低可读性。来源页、隐私说明与名称版本可见。

## 保存与版本契约

- 独立键 `oasis.tarot.records.v1`，`schemaVersion: 1`，最多 50 条。卡牌目录、名称版本、记录规则与现有易卦存储相互独立。
- 每条含唯一 ID、UTC 保存时间与完整文字快照：问题、记录日期、牌组说明、抽取过程、牌阵名、每个位置与编号、每张牌的 ID／中文名／英文名／类别／大牌编号或小牌等级、正逆位、逐牌笔记、整体复盘、规则约定和来源。
- 从保存的快照回看并按其版本核验，没有重新抽牌或重新生成牌义。恢复到表单仅供用户另存，旧快照不随表单变化。
- 严格拒绝未知记录／牌名版本、未知牌 ID、重复牌、错误牌位顺序、错误名称／类别／编号、缺失规则或来源、异常保存时间、重复记录 ID 与未知存储 schema。
- 损坏数据导致列表读取、保存、删除与导出全部停止，不覆盖原存储。读取失败或 quota 写入失败提示用户重试；不先删除旧记录来腾空间。
- 删除需要页面确认。导出经统一 `exportJson` 工具输出全部完整快照；浏览器下载 JSON，其他端复制 JSON。未实现导入、云同步或账号上传。

## 来源与权利边界

已实际阅读以下原始／机构来源：

1. [V&A：A history of tarot cards](https://www.vam.ac.uk/articles/tarot-cards)：确认常见 78 张分为 22 大牌与 56 小牌、四花色及历史牌组差异。页面最近更新 2026-07-16。这里仅用于牌组结构核对，不复制馆藏照片或介绍正文。
2. [A. E. Waite：《The Pictorial Key to the Tarot》Part II](https://en.wikisource.org/wiki/The_Pictorial_Key_to_the_Tarot/Part_2)：核对大牌名称和 RWS 力量 VIII、正义 XI 编号。数字化底本为 1922 重印本，其卷首记初版 1910。没有复制释义段落或原图。
3. [同书 Part III](https://en.wikisource.org/wiki/The_Pictorial_Key_to_the_Tarot/Part_3)：核对四花色和每花色的 Ace–Ten、Page、Knight、Queen、King 名称。原文牌义未导入。

本版以通用牌名、编号和分类事实独立编制文字牌目，中文用字自行整理；未抓取现代牌图、现代译文、牌义或馆藏摄影作品。网页公开可读不表示其中图片、字体、版式或现代译文自动获准再分发；如后续增加图像或释义，应另核具体素材来源与授权。名称版本表示本软件的用字和排序选择，不表示对某套出版物全部素材取得授权。

外部资料核对和测试只证明牌目、格式与记录行为符合本版规格，不证明牌名或牌阵具有现实测算有效性。

验证命令：`node --test tests/tarot.test.mjs`；`npm run typecheck`。路由、目录卡片、全局构建与浏览器界面验收由主线程统一整合。
