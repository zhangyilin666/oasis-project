# 八宅游年对照：实现前规格

2026-10-03。规则 `bazhai-sitting-true-v1`；仅坐山起伏位的大游年卦变文化对照。并不评价实际建筑的健康、财运或居住安全。

## 底本与独立参考

1. 《钦定协纪辨方书》四库全书本卷二“大游年变卦”，[固定修订787335](https://zh.wikisource.org/w/index.php?title=欽定協紀辨方書_(四庫全書本)/卷02&oldid=787335)。按初、中、上三爻，差异掩码分别为1、2、4；0伏位、1祸害、2绝命、3天医、4生气、5六煞、6五鬼、7延年。实现使用此卦变规则。
2. 《古今图书集成》艺术典676卷引《阳宅十书》“论大游年第三”，[影印对应转录修订1899482，第81扫描页](https://zh.wikisource.org/w/index.php?title=Page:Gujin_Tushu_Jicheng,_Volume_476_(1700-1725).djvu/81&oldid=1899482)。八首歌作为独立输入参考，不从实现反推。原书“天乙”与本版依《协纪辨方书》所用“天医”异名单列。该文库页尚未校对，因此不单独作为唯一依据，八歌须与前一底本卦变交叉一致。
3. 古籍原文属公版。本项目只提取卦变对应等事实，释义、步骤与示意自行编写，不搬运现代注释、图片、标点排版或有版权的现代书页。

## 测量约定

使用现代真北、顺时针0至360度系统。输入必须说明是坐山方向（朝向的反向）还是朝向方向；朝向加180度得到坐山。此为本产品明确选择的测量约定，不宣称古籍统一使用现代真北。

八方中心从北0度起，每45度一方；区间采用左闭右开，北方跨零点。测量不确定度必须明确填写，范围0至小于22.5度。若不确定范围触及/跨越方位边界则拒绝生成唯一坐山，提示重新核实。恰好在边界的零不确定度数学样例按左闭右开处理，不把未知精度当0。

缺度数、北向基准未知或只有磁北、缺测量工具/依据/日期、未选坐向含义均不出盘。不会自动估磁偏角；旧空间档案只读填入，不修改原记录。户型和时期只是原始事实，不参与游年映射；命卦、门起伏位、玄空飞星等不混入本规则。
