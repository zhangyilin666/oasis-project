## 时间与地点如何统一

手动偏移仍支持 UTC−12 至 UTC+14，以 15 分钟为步长，填写值应包含当时夏令时。选择 IANA 时区后，以设备 `Intl.DateTimeFormat` 的历史规则解析当地时刻，解析出的实际偏移和 UTC 瞬间随结果保存，保留历史偏移中的秒数。

重复的当地时刻必须选择较早或较晚的一次；因夏令时前拨或日期线变更而不存在的时刻直接报错，不自动平移。设备不支持历史时区、时区名称无效或数据不可用时会提示改用手动偏移，不悄悄套用当前时区。IANA 数据由设备提供，设备之间的数据库版本可能不同，保存快照有助于核对当时的解析结果。

出生日期从 1900 年起，拒绝不存在的日期、未来出生瞬间以及转换到北京时间后越界的资料。八字与紫微继续按同一出生瞬间换算到北京时间 UTC+8；西方盘使用 UTC。经纬度独立填写，不推断时区，也不据经度再次调整出生时间。北纬、东经为正，南纬、西经为负。

「大约时间」会保留精度标记并提示盘面只对应所填时刻，不计算时间误差范围或多个候选命盘。时柱、紫微命宫、星盘四轴与宫位都可能随实际出生时刻变化。

## 三盘新增规则

紫微观察日期必须为有效公历日期，不早于北京时间出生日期且不晚于 2099-12-31。按日比较，允许出生当天；固定取该日北京时间午时。未填写时仍只显示原有十三节本命资料，填入后追加运限五节。

紫微流年及虚岁以春节为界，流月按农历月；闰月前十五日随本月，十六日起随下月。大限从五行局对应虚岁起，每十岁一宫，阳男阴女顺、阴男阳女逆。时间轴所列年份是农历年份。未起大限时明确标为童限，超出十二段大限时不伪造当前大限。详见[紫微运限实现与参考](metaphysics-ziwei-flow.md)。

西方四轴以出生地几何地平圈、子午圈与当日真黄道的交点求得，不加入大气折射。整宫制从上升星座的 0° 起第一宫，MC 独立显示，不能等同第十宫起点。未填地点或纬度绝对值达到 66° 时，显示无法计算本期宫位的原因，仍保留基础天体和相位；66° 是本期产品支持界线，不是整宫制的普遍数学限制。详见[四轴、宫制与独立数值参考](metaphysics-houses.md)。

## 本机存储与导出

出生档案保存完整计算快照，包括输入资料、时间解析、可选观察日期、结果、计算约定、引擎来源及规则版本。查看快照不重算；「填入资料」用于重新生成结果，旧快照保持独立。名称为 1–40 个字；达到 30 份后拒绝新增，提示用户先导出并自行删除不需要的记录。至少一个体系成功计算后才能保存。

易卦单独记录 1–200 字的问题、日期、当地时间、UTC 偏移、方法和原始输入，按 `divination-v1` 复算。六爻不会自动套用梅花互卦与体用；梅花两数各为 1–999999 的整数。50 条上限不会淘汰旧记录。完整算法约定、古籍校核及验证见[独立易卦工具](divination-phase2.md)。

两类记录均只在用户点击保存后写入本机。格式损坏、未知版本或存储失败会提示，读取异常时不以空数据覆盖原记录。清理浏览器或应用数据会丢失这些档案；本期没有回收站或导入恢复界面。浏览器导出发起 JSON 文件下载，其他端复制 JSON 后需自行粘贴保存。导出含出生资料或问题，应由用户自行保管；导出成功提示不等于已完成云备份。
