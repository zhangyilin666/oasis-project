# 阶段八：太乙金镜岁计

页面为 `pages/taiyi/index`，独立域为 `src/domain/taiyi`。入口和浏览器验收由主集成负责。

## 本轮已实现

- 固定《太乙金镜式经》文渊阁四库本岁计，以开元十二年甲子（724）积年 1,937,281 为锚。公式、同卷其他纪元记载与选择依据随界面、快照及导出保存。
- 所求岁年 1–9999；年份仅标识所求传统岁年，不接收具体公历时刻，不暗定立春／春节／1 月 1 日换年；不支持公元前或 0 年。
- 积年、太岁干支、合神、360／72／24／18／60 周期及逐步除法；太乙三年一宫、乾坤重留的天目、计神、始击、主客逐步行算、主客大将参将。
- 太乙专用九宫编号与十六神分开展示；完整的算式依据，无占断、灾异、军事行动或吉凶建议。
- 第 39 与 50 阳局的原书主算与步骤不一致，主算及主将明确为空并显示待校勘。盘面其他可核实字段仍可保存，JSON 原样保留 `null`、冲突说明及核对步骤。
- 本机完整快照、30 份上限、刷新回看不重排、复制输入再算、单份／全部 JSON 导出、删除确认、错误存储阻止写入；不上传或调用 AI。

## 验证与文献

36 项 `node --test tests/taiyi-chart.test.mjs` 通过，包括：23 条在引擎前手抄的卷三阳局固定值、4 份古例将位、2 处待校勘、724 锚、满周期零余数、乾坤重留、跳中五、72 局结构遍历与档案读写。全项目 `npm run typecheck` 已通过。

完整出处、原典与独立实现差异见 [taiyi-validation.md](research/taiyi-validation.md)。主客算按卷二公式独立实现，测试取自卷三与卷六／九事实记录，不用自身输出作期望。候选 kintaiyi 只做固定 SHA 的源码对照，未安装、运行或复制代码／pickle／天文数据。其第 44 局主算与第 67 局始击有别于原典和步骤；本版不沿用这些差异。

没有实现月、日、时、分计、命法、其他积年法、五福、大小游、八门、其他神煞或自动断语；界面已明示。全部 72 局结构遍历不能替代全量外部真值校验。

浏览器建议验收：724 → 积年 1,937,281、阳 49 局、太乙乾一、天目巽、始击辰、主算 24、客算 25；714 → 阳 39 局、主算及主将待校勘、客算 34；两种结果都能保存、刷新回看与导出。
