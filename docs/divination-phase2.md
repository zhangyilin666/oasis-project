# 第二阶段：独立易卦工具

2026-10-03。页面路由：`/pages/divination/index`。

## 已接入

- 六爻记录：用户按初爻至上爻输入六个 6/7/8/9。6 为阴动爻、7 为阳静爻、8 为阴静爻、9 为阳动爻；生成本卦、变卦和动爻序号。可同时出现 0 至 6 个动爻。
- 梅花两数简化法：第一数取上卦、第二数取下卦；两数分别除 8 取余，余 0 取 8；两数和除 6 取动爻，余 0 取第 6 爻。两数限制为 1 至 999999 的整数。
- 互卦按本卦第 2/3/4 爻组成下卦、第 3/4/5 爻组成上卦。包括乾坤取自身的结构互卦；页面明确说明没有采用“乾坤无互，互其变卦”的另一约定。
- 体用按本卦唯一动爻所在经卦为用，另一经卦为体；仅输出本卦五行的比和、生克方向，不输出吉凶判断。
- 问题、公历日期、当地时间和 UTC 偏移均显式记录。问事时间不加入两数简化法，重新生成不会引入随机数。
- 本地手动保存，最多 50 条；第 51 条拒绝保存，保留旧记录。单条删除需确认。读取失败、未知版本、损坏数据或存储写入失败会提示，不静默覆盖原数据。
- JSON 导出包含原始输入、问事时间、方法、规则版本和可复算结果。浏览器下载文件，其他端复制后由用户保存；无账号同步，无上传，无 AI 调用。

## 古籍与符号校核

核验于 2026-10-03，只使用古籍基础规则、卦名及上下卦组合，未复制现代解释或翻译：

1. [《周易本义》四库全书本·卷一](https://zh.wikisource.org/wiki/周易本義_(四庫全書本)/卷1) 与 [卷二](https://zh.wikisource.org/wiki/周易本義_(四庫全書本)/卷2)：核对完整六十四卦的卦序及经文中的上下卦标注。页面中的正文会重复“艮下坎上”，校核时将该处视为蹇卦解释而非新增卦项。卦名显示简体字，第 33 卦遯显示为遁。
2. [《梅花易数》卷一](https://zh.wikisource.org/zh-hans/梅花易數/卷一)：核对先天卦数、八卦形状、八宫五行、五行生克、取余及互卦结构。工具“两数、不加时”的取法是明确的软件约定，不宣称等同古籍所有起例。
3. [《梅花易数》卷二](https://zh.wikisource.org/zh-hans/梅花易數/卷二)：核对体用动静关系，并以卷一观梅与牡丹例校核下卦动/上卦动时的体用方向。
4. [Unicode 六十四卦符号编码表](https://www.unicode.org/charts/PDF/U4DC0.pdf)：核对 U+4DC0 至 U+4DFF 与卦序的对应，仅实现字符码点映射，不分发原 PDF 或其中字体。页面直接绘制阴阳爻，不依赖用户设备字体覆盖该区段。

## 范围与后续

六爻页面定位为“六爻记录／基础卦象”。尚未实现纳甲、世应、六亲、六神、月建日辰、旬空和旺衰等完整六爻排盘能力。互卦、体用只出现在梅花两数结果中，避免将该体系自动嫁接到六爻记录。

保存结构使用独立键 `oasis.divination.records.v1`，仅保存规则版本与复算必需的原始输入。没有读取或修改认证及三盘档案。规则版本为 `divination-v1`，将来算法变化时需要保留旧版本复算或实现显式迁移。
