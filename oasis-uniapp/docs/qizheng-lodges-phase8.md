# 清历宿度查算：最小传统底本功能

新增独立页面 `pages/qizheng-lodges/index`，在明确输入古法宿钤年标号和黄道宫度后，按《历象考成》康熙甲子黄道表查算二十八宿及入宿度。

## 已实现

- 28宿第一星黄道经度，逐幅核读原表；不等宽、参前觜后和跨周天边界均保留。
- 1684–2099年标号，统一按51角秒/年作整年宿表推移；非基准年明确提示未核当年实测或修订表。
- 宫/度/分/秒明确输入，原书太阳例按钮，本宿起点、下一宿、剩余宿度和完整28宿表。
- 本机最多20份完整快照、2000字笔记、历史回看、单份和集合JSON导出；读取失败停止写入。
- 方法、底本、原图编号、独立古例、已知异文和未实现范围的可追溯文档。

## 边界

本页不接出生资料和现代七政位置。年标号不是由公历时间戳自动得出，坐标零点为冬至，不能直接填西方热带星座名称。春分零点显示仅为坐标转换。1684–2099是产品范围，不代表所填年天体或距星的真实位置精度。

没有声称完成七政四余全盘。四余传统算法、赤道入宿度、立命与运限仍未核；主七政页面不改名、不混用宿度表。
