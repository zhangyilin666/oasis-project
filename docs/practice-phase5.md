# 静心修习计时与本机记录

实现：`oasis-uniapp/src/domain/practice/`、`oasis-uniapp/src/pages/practice/index.vue`。三种导读均为本项目原创：安静坐一会、留意周围声音、整理今日思绪。无需出生信息，不进行命理推断或医疗效果宣传；不申请声音、通知或后台权限。

## 计时与恢复

- 每个 1–60 分钟整数均可选，默认 5 分钟。支持开始、暂停、继续与提前结束。
- 规则版本 `practice-timer-v1`。草稿保存 `elapsedMs` 累计运行毫秒、`anchorAt` 当前运行段的系统时间锚、`lastObservedAt` 最近观察时间。页面 250ms 刷新只用于显示，计时依据 `Date.now()` 的时间差，不依赖 interval 回调次数。
- 暂停清空运行锚并保留已用时，继续以当前时间建立新锚；暂停期间不计入累计时长。
- 跨后台或刷新，按保存的锚点补算经过时间。uni `onHide/onShow/onUnload` 与 H5 `visibilitychange/beforeunload` 保存／恢复；隐藏页面停止界面刷新。突然关闭时，最近一次已保存的运行锚仍可用于重算经过时间。
- 到时将累计时长封顶于计划时长，计算逻辑截止时刻，保持完成草稿。剩余时间始终大于或等于零；重复投影或重复结束不会多次完成。
- 运行时发现当前时间早于最近观察时间，暂停并保留累计时长，记录回拨次数与检测时间，提示用户确认设备时间后手动继续。时钟自行恢复不会补加回拨期间的时间。

这是使用设备墙上时钟的计时器。设备时间向前跳跃可能使计时提前到期；没有声称在设备时钟被任意修改后仍具备独立计时精度。回拨检测以最近保存或当前页面已观察的锚点为准，关闭页面后没有额外的系统级时钟服务。

## 草稿、笔记与记录

独立存储键：`oasis.practice.sessions.v1`。完整 schema 一次存储 `active` 草稿和最多 50 条 `records`，不与其他板块混用。

状态切换、笔记输入、离开页面及回到页面时保存草稿。笔记保留原始空白和换行，最多 2000 字。完成后不会自动丢弃草稿，也不会立即生成历史记录；用户点击“保存笔记为练习记录”后，在一次存储写入中创建记录并清空相同草稿。

记录沿用会话 ID；重复提交返回既有记录，不生成副本或覆盖其笔记。保存时保留完整主题导读、时长、时钟状态、笔记和规则版本；刷新回看使用原样快照，不套用之后更改的主题文案。删除草稿、删除记录均需页面确认。

草稿写入失败时，页面保留当前进度与输入，显示未写入错误，并提供重试和导出当前草稿。返回页面时优先保留待保存的内存草稿，不用磁盘旧值覆盖它。写入完成记录失败时，磁盘上原有完成草稿仍保留，可重试提交。容量满时也保留完成草稿，提示先导出或删除旧记录。

损坏 JSON、缺失字段、无效锚点或时长、不兼容版本、重复记录 ID、活动草稿与记录 ID 冲突等情况均阻止写入，保留原始数据。旧的运行回调不能将已完成草稿重新改为运行状态。提供当前草稿、单条记录、草稿与全部记录三类 JSON 导出；H5 发起下载，其他端复制 JSON 并明确提示自行粘贴保存。

## 验证

`node --test tests/practice.test.mjs`：18 项通过。测试使用注入的数值时钟，不需要真实等待。

- 三主题与全部 1–60 分钟选项、无效时长、无效系统时间。
- 相同墙上时间差在不同 interval 回调数量下结果一致。
- 暂停不累计、继续建立新锚、后台与重建仓储后的刷新恢复。
- 超时封顶、精确到时边界、非负倒计时、完成幂等。
- 时钟回拨暂停、已用时不减不增、继续后的新运行段、回拨状态刷新保留。
- 提前结束、笔记空白和长度保护。
- 完成草稿刷新保留，手动保存一次，重复保存不覆盖，历史导读原样读回。
- 草稿写入与完成提交失败的旧数据保护及重试、50 条上限、定点删除。
- 损坏或不兼容存储不覆盖，读取权限错误明确返回。

浏览器操作、多宽度截图与生产导出读回交由集成流程验证；单元测试不替代浏览器验收。
