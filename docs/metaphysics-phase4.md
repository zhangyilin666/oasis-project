# 第四批：六爻纳甲、黄历日期浏览与规则对照

日期：2026-10-03。承接[十八项总路线](metaphysics-integration-roadmap.md)与[第三批](metaphysics-phase3.md)。本批围绕已有历法和记录功能，增加三个可独立使用的入口；奇门、六壬、太乙、七政四余及印度占星仍按原研究门槛推进。

## 使用入口

| 功能 | 入口 | 本批范围 |
| --- | --- | --- |
| 六爻纳甲 | 五术探索 → 易卦工具 → 六爻纳甲 | 六爻手录；八宫、世应、纳甲、六亲、六神、旬空及动爻变出；缺亲伏神候选与日期事实 |

| 八字／紫微规则对照 | 三盘同参 → 时区、地点、观察日期与规则对照 → 开启对照 | 主盘保持既定规则，追加有限方案的差异与参数，不自动选择“更准”的方案 |

新功能继续在设备上确定性计算，复用已有锁定依赖，不新增后端服务。现有账号报告、首页当日黄历服务和出生档案保持各自入口。

## 规则、资料与版本

六爻纳甲另注册 `liuyao-najia` 与 `liuyao-najia-v1`，避免新算法改变旧六爻基础记录。输入当地日期、钟表时间和有效 UTC 偏移，换成 UTC 瞬间后采用固定 UTC+8 的月建与日辰。变爻六亲以本卦宫五行为基准；伏神展示缺亲候选，不自动选用神或断应期。规则、来源、参考例及实际开放范围见[纳甲说明](divination-phase4.md)。

黄历浏览使用固定 UTC+8 的日期与观察时间。历法／节气事实与传统宜忌分别展示，不能把单日宜忌当作完整择日结论。交节时刻保留引擎数据及外部参考的精度边界。详见[黄历说明](almanac-phase4.md)。

规则对照为可选计算参数 `compareRules`。八字分别对比晚子换日和起运算法；紫微分别对比春节／立春日年界、晚子换日。紫微上游的 `yearDivide=exact` 在当前锁定版本中采用立春**当日**，不能按字段名宣称它精确到交节秒。各方案固定其余参数，并在比较调用前后隔离全局配置。详见[规则对照说明](metaphysics-rules-phase4.md)。

出生结果总规则版本为 `4.0.0`；结果中的可选 `ruleProfile` 记录主方案、对照版本与方案 ID。档案格式仍为 `schemaVersion: 1`。旧快照不重算，载入旧资料时对照开关默认为关闭；新档案保存本次开关与实际生成的对照章节，导出带相同内容。
