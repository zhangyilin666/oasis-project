# 西方星盘第二阶段：四轴与整宫制

更新：2026-10-03。

## 已实现的范围

共用出生资料中的 UTC 瞬间与可选 `place.latitude`、`place.longitude`，输出上升点 ASC、下降点 DSC、天顶 MC、天底 IC、整宫制十二宫，以及十天体落宫。经纬度为地理坐标，东经和北纬为正，西经和南纬为负。地点名称不参与数值计算。

无经纬度时保留基础星盘。合法但绝对纬度大于或等于 66° 时，明确提示本版暂不支持宫位，行星位置与相位仍正常输出。66° 是本期为极圈附近情形设置的保守产品边界，不是整宫制在该纬度必然失效的数学结论。无效经纬度由入口校验；宫位适配器也有独立防御。

## 几何方法与约定

运行时继续使用已安装的 MIT 许可 `astronomy-engine@2.1.19`。地平坐标 HOR 的正方向依次是北、西、天顶，EQD 为当日真赤道，ECT 为当日真黄道。通过 `Rotation_HOR_EQD` 和 `Rotation_EQD_ECT` 组合旋转取得地平面、子午面在 ECT 中的法向量，再以叉积求与黄道面的交线。这些坐标系与接口来自 [Astronomy Engine 官方 JavaScript 文档](https://github.com/cosinekitty/astronomy/blob/master/source/js/README.md)。

- ASC 选择几何地平圈的东侧交点，MC 选择子午圈的地平线上方交点。
- DSC 与 IC 分别是 ASC 与 MC 加 180° 后归一化的对点。
- 宫位使用未四舍五入的热带黄经。上升点所在星座的 0° 为第一宫起点，此后每个完整星座依次成为下一宫。
- MC 独立保留，可能处于第九、十、十一宫，不能用整宫制第十宫起点替代 MC。
- 不加大气折射、地形地平线或海拔修正；不以出生地经度再次修正已归一化的 UTC 时刻。

整宫制的起点定义采用 [Astrodienst 官方文档 6.2.5](https://www.astro.com/swisseph/swisseph.htm) 的 Whole Sign 约定。此实现不包括 Placidus，也不同于从 ASC 精确度数起算的等宫制。高纬度的特殊交点选择有不同流派约定，本期不把这些情况静默切换到其他宫制。

## 验证

`node --test tests/metaphysics-houses.test.mjs` 覆盖六组独立 ASC／MC 参考、南北纬至 ±65.99° 的地平圈与子午圈几何条件、整宫边界、0°／360°、±180° 经度等价、每个天体只归入一宫，以及缺少／无效／极圈地点时保留基础盘。

几何测试另外通过 `Horizon` 的高度、方位和赤经／地方恒星时关系检查角点，避免只检查数组长度与显示文字。计算逻辑在 `src/domain/metaphysics/houses.ts`，现有星盘适配器 `western.ts` 把结果作为 `ChartResult.summary` 和 `sections` 输出，界面无需理解星盘算法。
