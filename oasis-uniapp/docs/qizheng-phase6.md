# 七政天文对照首期交付

新增独立页 `src/pages/qizheng/index.vue`，以可保存的天文参考表作为七政四余的最小已验证子体系。范围不是完整命盘：本期开放日月五星的黄道、赤道坐标与现代去极度，四余、宿度、宫度、立命和运限明确待校核。

## 可使用的流程

- 自行输入公历日期与当地时刻，明确精度、UTC 偏移或历史 IANA 时区。可读取本机三盘档案的时刻字段，也可用“使用此刻 · UTC+8”记录当前采样。
- H5 日期／时间是可键盘输入的文本框，枚举为原生 `select`；其他平台保留 `picker`。没有初始默认出生时刻。
- 在黄道与赤道页签之间切换，查看七政的完整现代坐标；赤经同时展示小时形式与角度形式，去极度按现代360°单位标注。
- 填写记录名称和最多2000字的对照笔记，保存完整快照；打开、删除，或导出当前／全部记录。
- 查看每项未开放规则的依据和缺口，直接打开原始参考链接。

输入采样日期范围为1900–2099，支持研究未来天体位置；带时区偏移的范围端点可能换算到1899年底或2100年初。当前模型支持这些边界计算，测试包含两端。该页面没有对出生时刻做吉凶推断，因此不将未来日期冒称出生记录。

## 算法与证据

计算使用已有 MIT `astronomy-engine@2.1.19`，独立规则版本 `qizheng-modern-coordinate-reference-v1`。共168个独立参考坐标来自 Swiss 官方公开服务，六个不同日期均通过0.02°容差；样例最大差19.93216角秒。另核对了服务赤经返回列的实际单位。细节见 [规格与验证](research/qizheng-validation.md)。

未添加任何 Swiss 依赖，没有用西洋外行星冒充四余，也没有把黄经均分28段。二十八宿的星表／历元／黄赤口径缺口已经写入结果与导出快照。

## 本机快照

独立存储键 `oasis.qizheng.reference-snapshots.v1`，最多20份、约50万字符。记录包含名称、笔记、保存时间、原始采样资料、解析的 UTC、全部七政数值、坐标单位、规则／引擎版本、未开放能力、来源与限制说明。

打开记录不重新计算。修改采样表单使旧结果失效，避免新输入与旧数值混合。未知版本、损坏、重复ID或读取失败不会静默清空存储，并阻止覆盖；容量满时不自动删除旧记录。写入失败可导出当前内存结果。
