# 印度占星首期交付

新增独立的印度占星页 `src/pages/jyotish/index.vue` 与 `src/domain/jyotish/` 计算／存储模块，不向原有三盘 `SystemId` 添分支，也不复用西洋星盘结果换标题。

## 用户流程

1. 填写出生日期、实际时刻并明确时间精度。可从本机三盘档案仅读取出生资料；通用性别字段仅留档，不参与算法。
2. 选择手动 UTC 偏移或填写历史 IANA 时区；夏令时重复时刻必须明确选择。地点可选，缺失时仍可看七曜基础盘。
3. 查看七曜 D1／D9、月宿与足、出生大运余额、指定日期的大运和分运。每个大运可展开九个分运。
4. 保存、打开或删除本机快照，导出当前结果或全部档案。修改表单会使旧结果失效，避免把新输入与旧结果一并导出。

观察日期采用北京时间 12:00。未知时刻不默认中午；近似出生时刻会显示明确提示并停用角度／宫位。高纬度也有独立不可用状态。

## 固定规则

- 引擎 Astronomy Engine 2.1.19（已有 MIT 依赖），未增加 Swiss Ephemeris 依赖。
- 模型 `lahiri-p03-approx-v1`；整体规则 `jyotish-seven-lahiri-p03-v1`。
- 日月水金火木土七曜，地心视黄经减真岁差值。
- 整宫制按恒星上升星座开始；D9 用 Parashari 九分法。
- 27 等分月宿、每宿四足；Vimshottari 每年固定 365.25 日，完整大运／分运区间含起点、不含终点。
- 未开放未验证的罗睺／计都坐标、其他分盘、瑜伽或吉凶解释。

来源、数值、误差与年长差异的处理详见 [研究与独立校验](research/jyotish-validation.md)。

## 快照与存储

存储键为 `oasis.jyotish.snapshots.v1`，上限 20 份、序列化约 150 万字符。快照包含出生输入、解析后的 UTC／偏移、观察时刻、引擎和规则版本、七曜、D9、宫位、月宿、大运及分运、来源和限制说明。

读取仅验证结构与已有数据的一致性，不重新请求天体位置。未知版本、损坏数据、重复 ID、读取失败不会自动清空旧内容，也会阻止后续覆盖。保存只在完整写入返回后报告成功；写入失败仍可导出当前内存结果。

三盘档案只通过 `createChartArchive().list()` 读取。独立印度占星记录与原来的三盘、黄历、修习存储互不改写。支持明确删除确认，不自动淘汰历史记录。

## 验证状态

- 21 项专项测试：42 个独立七曜值、6 个岁差值、4 组 ASC／MC／宫头，D9 教材例题、月宿余额例题、108 个 D9 分界与 27 月宿分界，周期连续性与精度，时区／近似输入，存储恢复与错误路径。
- 六时刻样例七曜最大差 15.9854 角秒；这是样例测量值，不是全范围误差保证。
- 全项目 `npm run typecheck` 已通过。
- 页面注册、主入口接入与最终浏览器／构建验证由集成步骤完成；本文件不把未执行的浏览器检查标记通过。
