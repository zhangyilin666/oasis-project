# 六爻纳甲事实层交付

更新日期：2026-10-03。新增独立方法 `liuyao-najia`，规则 `liuyao-najia-v1`。原 `liuyao-manual`、`meihua-two-numbers` 的 `divination-v1` 与 `meihua-calendar-v1` 均保留原计算语义；旧六爻记录不会自动升级成纳甲盘。

## 已接入

- 原始六次爻值自下而上输入：6 老阴、7 少阳、8 少阴、9 老阳。6、9 变爻，保留本卦、变卦与动爻。
- 八宫、宫五行、本宫至归魂的八个阶段、世爻与应爻。
- 内外经卦纳甲干支、地支五行、六亲。动爻变出使用变后经卦纳甲，六亲始终以**本卦所属宫五行**为基准；静爻不标成动爻变出。
- 本卦缺亲时，从本宫纯卦同位取伏神候选，展示同位飞神。按整个本卦缺亲集合列候选，不自动选用神，不自动把月日或变爻当作用神。保留所有同位候选，不任取第一项。
- 问事地时间及手动 UTC 偏移 → UTC 瞬间 → 固定 UTC+08:00 演算时间。月建以十二“节”准确交接时刻换月，日辰以 00:00 换日；23:00 不提前换日。
- 六神从同一日干起初爻向上排；旬空从同一日干支所属十日旬导出。本爻、动爻变出及伏神候选均可标注纳支旬空。
- 显示当前节与下一节的引擎交接时刻、完整演算过程、规则约定及来源。移动端以逐爻卡片自上而下展示，避免宽表横向滚动。
- 本机手动保存、复算、删除与 JSON 导出支持四种方法；严格验证方法与版本配对，异常原记录保持原样。

不生成吉凶评分或自动占断；本轮未接用神选择、旺衰、进退神、应期与出伏判断。这里的旬空是传统结构标记，不代表现实事件必然失效。

## 规则与实现

`oasis-uniapp/src/domain/divination/najia.ts` 独立实现结构层与历法适配层，无新增运行时依赖。结构层 `buildNajiaStructure` 可以脱离日期换算穷举检验，日期层复用已锁定的 `lunar-typescript@1.8.6`。

初爻为最低位，相对纯卦的八宫掩码为 `[0,1,3,7,15,31,23,16]`，世爻依序为 `[6,1,2,3,4,5,4,3]`。测试真值为独立读出的八宫卦名顺序，并非由掩码生成。

纳甲采用传统内外表，乾内甲外壬、坤内乙外癸，其余经卦内外同干；六亲取纳支五行，不取纳音，也不取天干五行。以宫五行为我，同我兄弟、生我父母、我生子孙、我克妻财、克我官鬼。变爻继续用原宫，因此夬变姤的变初丑土、变上戌土均为兄弟。

日柱只用 `getDayInGanZhiExact2()`，随后拆日干日支并派生六神和旬空。月建使用 `getMonthZhiExact()`，当前节与下一节使用 `getPrevJie(false)`、`getNextJie(false)`，不混用“交节当天零点”口径。

新法的输入日期、换算后 UTC 日期、演算 UTC+8 日期均须在 1900–2099。原两种 v1 方法保持原范围语义。手动偏移由用户确认，须包含当年的夏令时；本功能没有 IANA 自动查时区，也不能自动判定某地跳时是否存在。夏令时重复钟表时间可用两个不同有效偏移表达两个瞬间。

## 验证

`tests/divination-najia.test.mjs` 新增 16 项测试，连同原六爻/两数 11 项及梅花时间 12 项，共 39 项：

- 独立具名八宫全表对 64 卦，全部 48 个纳甲干支、25 种六亲关系。
- 穷举 4096 种动静输入，核对初至上方向、原宫不变、变后经卦纳甲与仅动爻变出。
- 古籍固定变爻六亲案例、六组固定伏神案例；全 64 卦按缺亲集合核对全部候选。当前全表没有同一缺亲重复伏位，确有多种缺亲同时出现；测试不臆造不存在的重复案例。
- 十干六神、完整六十日旬空；独立日历例、全年十二节前后、23:00/00:00、旬交界、春节不切月建。
- 同一瞬间跨六种偏移、跨日、手动重复钟表时间的不同偏移、范围与无效爻值。
- 四种方法版本共存；所有不匹配组合在读、写、复算、删除和导出中拒绝，且不覆盖原记录。原版本测试全部保留。
