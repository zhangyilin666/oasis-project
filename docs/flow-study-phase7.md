# 流年流月研习 · 独立时间与分层四化

本轮新增 `/pages/flow-study/index`，只读复制三盘档案中的 `BirthProfile`，也可以手动录入。出生和观测各自有日期、时分、手动 UTC 偏移或 IANA 时区、重复时刻选择。保存原输入、解析偏移、UTC 时间、UTC+08:00 时间以及完整结果；不改变旧三盘的类型、接口、主盘口径或旧快照。

规则版本 `flow-study-v1`，引擎固定为已安装的 `lunar-typescript 1.8.6` 与 `iztro 2.6.1`。没有增加运行依赖。

## 计算边界

输入的出生与观测公历日期都支持 1900–2099。出生时间沿用已有 `normalizeBirth`，不能晚于当前时刻；观测允许未来，但必须在 UTC 意义上不早于出生，而不是只比较两份当地日期。

所有引擎输入都先转到固定 UTC+08:00，不依赖设备默认时区，不校正真太阳时。观测时分必填，不以正午替代未知时间。IANA 解析复用现有 `resolveZonedTime`，不存在的当地时刻报错，重复时刻要求明确选较早或较晚；输出保留实际解析偏移，包括历史秒级偏移。设备 IANA 数据属于运行环境，历史快照读回不重新解析时区。

### 八字节气年与十二流月

- 沿用 `bazi-day2-yun1` 的主盘日柱口径：`EightChar.setSect(2)`。晚子日柱归当天，时干沿用该库次日时干。每次使用独立 EightChar，没有全局 sect 状态。
- 观测流年使用 `getYearInGanZhiExact()`，立春交节瞬间切年；流月使用 `getMonthInGanZhiExact()`，十二节交节瞬间换月。
- 生成观测所在节气年的立春至次年立春十二区间；起点包含、终点不包含。每行保留前后节名、UTC+08:00 起止、月干支、对出生**日主**的天干十神和藏干十神。
- 一月／立春前日期属于上一节气年。1900 年初的区间可始于 1899；2099 年尾的完整区间可结束于 2100。这些区间端点用于说明输入范围内的事实，未开放范围外观测。
- 交节字段显示至秒是引擎表示精度。本轮外部天文核对是分钟级夹逼，不声称亚分钟独立认证。
- 本页只扩展八字流年／流月；不把 `LiuNian.getYear()` 的公历标签当成交节后的当前流年，也没有新增大运、格局、吉凶或事件预测。

### 紫微七层结构

固定 `yearDivide=normal, horoscopeDivide=normal, ageDivide=normal, dayDivide=current, algorithm=default, fixLeap=true`，与旧主盘相同。春节换流年与虚岁；出生及观测的闰月后半月（十六日起）按下一月参与流月定位；晚子输入索引 12，在 current 规则下按当日早子索引 0。原输入索引与生效索引同时保留。

依序输出本命、大限或童限、小限、流年、流月、流日、流时。每层保存命宫所在本命宫、干支、十二宫对应、四化与十二宫流曜。四化逐个标明星曜所在**本命宫**，不把流限命宫的移动误作星曜物理位置变化。小限四化来自所在本命宫干；本命与小限没有本层流曜。

流日宫位从流月宫位按农历日序推移，流时宫位再按时支推移。日、时干支沿用 iztro 当前规则，所以晚子时的八字时干与紫微时干可能不同；两套结果各自标注，不强行合并。

小限年龄表只涵盖 1–120 虚岁；十二大限也有有限年龄上界。超范围时原库可能带回 `index=-1` 与默认甲子干支。本适配器明确输出 `unavailable`，干支／宫位设为空，四化和流曜为空；其他仍有定义的流年／月／日／时照常显示。起大限前依该库童限规则展示。

### 全局配置隔离

iztro 配置是全局的，四化与亮度表采取合并，`astro.config({mutagens:{}})` 不会清除已有表。新适配器在同步调用内：

1. 克隆当前五个标量、四化表、亮度表，记下当前语言。
2. 清空内部表对象，设置固定主盘口径及简体中文。
3. 创建星盘及观测运限，立即转成纯数据。
4. `finally` 清空临时表，恢复标量、原内部规范化键表和原语言；异常分支同样恢复。

没有向应用添加第三方 iztro 插件；同步计算没有 `await` 造成配置中间态泄露。旧适配器的行为未修改。

## 记录与交互

使用共享快照存储，独立键 `oasis.flow-study.records.v1`、封装 `schemaVersion=1`、`kind=flow-study`，最多 20 份、序列化长度上限 1,500,000。研习名称 1–40 字，笔记最多 2000 字。

完整保存原输入、两份时间解析、出生与观测四柱、十二流月区间、紫微七层与宫位事实、版本及来源。读回仅检查版本、字段、时刻数学关系、区间连续性、十神字典对应、宫位／四化关系，不调用排盘或时区引擎。这里是结构与内部一致性检查，不是防篡改签名，也不声称可以离线证明天文来源真实性。

未知版本、损坏 JSON、不一致时间或宫位等使列表、保存、删除、导出全部停止，保留原始内容；不会静默覆盖。达到容量时提示导出／整理，存储失败不显示成功。

页面提供公开示例、手动出生资料、只读复制旧档案、分层按钮、可展开的十二流月／十二宫、保存、原样打开、确认删除、JSON 导出。所有会改变计算的输入都同步清空旧预览及保存状态。旧档案读取错误只影响复制入口，不妨碍手动输入。
