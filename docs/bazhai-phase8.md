# 八宅游年对照：第八批

2026-10-03。已接入空间档案页和独立 `/pages/bazhai/index` 页面。范围仅为明确真北、坐山起伏位的大游年八方文化对照，使用 `bazhai-sitting-true-v1`，不包含命卦、门起伏位、玄空或房屋效果评分。

## 规则及资料

实现前规格、古籍版本和独立样例记录见[八宅验证规格](research/bazhai-validation.md)。运行时用《协纪辨方书》大游年卦变，不把小游年映射混用；参考测试独立录入《古今图书集成》所引《阳宅十书》的八首游年歌核对64格。天乙／天医异名在来源中保留。

资料是古籍公版事实；解释和示意由项目编写，未引入付费引擎、现代书页、星性断语或新增依赖。

## 资料及快照

支持新填写或只读填入空间档案。明确坐山/朝向、真北、原始度数、不确定度、测量对象、工具、依据与日期；缺方向、磁北或未知基准不生成盘。不确定范围触及八方分界时拒绝唯一归类。方向区间采用现代0°真北顺时针、45°八方左闭右开约定，明确不是所有流派的共同口径。

独立本机键 `oasis.bazhai.records.v1`，最多30份；包含完整SpaceFacts、八方星名、逐爻差异、推导、来源与规则版本。保存不修改旧空间档案，回看不重排。表单改动后仍显示旧结果且禁止保存，直到重新计算成功。
